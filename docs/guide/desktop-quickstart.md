# 快速开始：桌面端

Ollupi 是 macOS 上的 AI 代理应用。你在自己的项目文件夹里和它对话，它能读写文件、跑命令、上网查资料，做有风险的事之前会先问你。这一页带你从下载到跑通第一个任务。

## 下载安装

需要 macOS 12 或更新，只支持 Apple 芯片（M 系列）。

1. 打开 [Releases](https://github.com/0xfakeSpike/ollupi-desktop/releases/latest)，下载 `Ollupi-<版本>-arm64.dmg`。
2. 打开 dmg，把 Ollupi 拖进"应用程序"。

### 第一次打开

应用还没有经过 Apple 公证，第一次打开时 macOS 会提示无法验证开发者。点"完成"，然后选一种方式放行：

- 打开 **系统设置 → 隐私与安全性**，拉到底部，点"仍要打开"。
- 或者在终端里执行：

  ```bash
  xattr -dr com.apple.quarantine /Applications/Ollupi.app
  ```

只需要做一次。之后有新版本时，侧边栏底部会提示，点 **下载并安装**，下载完点 **立即重启**。不重启的话，退出 Ollupi 时也会装上。

## 添加模型提供方

Ollupi 不自带模型，要接你自己的 API。

1. 打开 **设置 → 模型**，点 **添加提供方**。
2. 选 API 类型：OpenAI 兼容（OpenAI、DeepSeek、本地服务等）、Anthropic 或 Gemini。
3. 填名称、Base URL 和 API 密钥。Base URL 留空就用这个 API 的默认地址。OpenAI 兼容的地址要带版本，比如 `.../v1`。
4. 模型列表会自动拉取。勾选要用的模型。上下文和输出上限能自动填的都会填好，填不上的留空就用默认值。本地小模型请按实际窗口填写。
5. 点 **保存并重启**。

新安装的应用里已经有一个没填密钥的 `openai` 提供方。如果你要用 OpenAI，直接编辑它，填上密钥就行。如果用别的提供方，在模型旁边点星标把它设为默认，再删掉 `openai`。

## 第一个会话

1. 点侧边栏底部附近的 **添加工作区**，选一个项目文件夹。工作区就是一个项目文件夹，代理的命令在里面运行。
2. 点 **新会话**，在输入框的工具栏选工作区和模型。
3. 描述任务，按 Enter 发送。可以粘贴或拖入图片和文件。

不选工作区也能聊天，这时命令在 `~/.ollupi/scratch` 里运行。

代理工作时可以继续输入：

- **插话**（Enter）：代理马上看到，并据此调整。
- **排队**（⌥Enter）：等这一轮做完再发送。
- **停止**：点输入框里的方块按钮。

## 审批

代理要做需要确认的操作时，对话里会出现一张卡片，告诉你它要跑什么命令、改哪些文件。你有这些选择：

| 按钮 | 意思 |
|---|---|
| 允许一次 | 只放行这一次 |
| 在此会话中允许 | 这个会话里相同的操作不再问 |
| 总是允许 | 写一条规则，以后都不问 |
| 拒绝 | 不做，代理会收到拒绝 |

如果卡片说"在沙箱外运行"，要多看一眼。沙箱是命令的安全围栏，跑到外面的命令能访问你账号可访问的所有文件和网络。

审批策略有三档，在 **工作区设置 → 权限** 或会话右上角的 **会话权限** 里改：

| 策略 | 什么时候问你 |
|---|---|
| 严格 | 只有读取本机文件的操作直接执行，会改动内容或联网的都先问 |
| 适中（默认） | 读取内容、在沙箱里运行的命令直接执行，其他改动和要跑到沙箱外的命令先问 |
| 宽松 | 不再询问，要跑到沙箱外的命令直接拒绝 |

有时代理会向你提问，比如让你选一个方案。选一个选项或自己写答案，提交后它接着做。

应用不在前台时，需要审批、需要回答或一轮结束都会发系统通知。

## 用好工作区

- 侧边栏按工作区分组列出会话。把鼠标移到工作区名字上，能打开文件夹、进工作区设置、归档，或在这个工作区里新建会话。
- 工作区设置里可以改名称和权限。这里的权限对工作区里所有会话生效。

会话右上角有几个面板，和对话并排显示：

| 面板 | 用来 |
|---|---|
| 浏览器 | 代理和你共用的内置浏览器。需要登录的网站，你在这里登录一次，之后代理就能用 |
| 文件 | 浏览工作区文件，预览文本、图片、PDF |
| 改动 | 看 git 改动，暂存、丢弃、提交 |
| 终端 | 你自己的 shell，在工作区目录打开，不经过代理 |
| 任务 | 代理当前的计划和进度 |
| 会话权限 | 这个会话的审批策略和规则 |
| 上下文 | 上下文窗口用了多少 |

拖动面板左边缘调宽度，双击恢复默认。

回复里提到的文件可以点：单击在文件面板打开，⌘+点击用默认应用打开。

## 常用快捷键

| 按键 | 作用 |
|---|---|
| Enter | 发送；一轮运行中是插话 |
| Shift+Enter | 换行 |
| ⌥Enter | 一轮运行中排队 |
| ⌘K | 搜索会话、消息、定时任务和记忆 |
| ⌘Enter | 在改动面板里提交 |
| ⌘+点击 | 用默认应用打开文件 |
| ⌘Q | 退出应用 |

关掉窗口不会退出。应用留在后台，会话照常运行，通知照常发。点 Dock 图标回来，要退出用 ⌘Q。

## 数据在哪

配置和数据都在本机的 `~/.ollupi`：

| 位置 | 内容 |
|---|---|
| `~/.ollupi/config.yaml` | 配置，API 密钥也在这里 |
| `~/.ollupi/data` | 会话和记忆的数据库 |
| `~/.ollupi/attachments` | 随消息发送的文件的副本 |
| `~/.ollupi/skills` | 技能 |
| `~/Library/Logs/Ollupi/backend.log` | 后端日志 |

这些路径都能在 **设置 → 通用** 里打开。

后端起不来时，界面会显示原因和后端日志，改好配置后点 **重启后端**。

想手写配置，看 [配置](/desktop/config)。想在手机上用，看 [飞书配置](/desktop/feishu)。想知道它怎么工作，看 [概览](/guide/overview) 和 [桌面端架构](/desktop/architecture)。
