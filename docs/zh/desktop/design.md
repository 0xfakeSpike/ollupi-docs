# 设计语言

桌面端的视觉语言叫**石与苔**：一张给你自己的事情画的导览图。每个工作区是一块一眼认得出颜色的区域；进到一件事里，先看到结果，背后做了什么收成一句人话。它不做这一类产品的默认样子：灰色列表旁边一长串命令、路径、模型和 token，要人读完才知道事情到哪了。

所有组件只用 `packages/ui/src/theme.css` 定义的语义 token。这页是那份规则的提炼，完整准则在 ollupi-desktop 的 `packages/ui/DESIGN.md`；产品事实（为谁、原则）在 `apps/desktop/PRODUCT.md`。名字和标识见 [品牌](/zh/desktop/brand)。

## 为谁、出发点

用户是**有消费能力的成年上班族和专业人士**，不一定会写代码：要省心，也要体面、可信。所以没有吉祥物式的表情、没有像素、没有饱和的糖果色。

出发点是 PRODUCT.md 的第 0 条原则：**AI 是让事情变简单的。** 界面第一层只给结论、进展和要你做的决定；过程、命令、路径、模型、用量都是可以展开的细节。少一样要读的东西，就是多一分省心。

| 关键词 | 取舍时意味着 |
|---|---|
| **省心** | 第一层只放结论、进展和要你做的决定 |
| **一眼看清** | 侧栏是地图：哪片区域有事、哪件在做、哪件等你，不用点开就知道 |
| **诚实** | 在跑就显示在跑，失败就显示失败；后果说得准的才写，说不准的不编 |
| **体面** | 大留白、低饱和、圆润，但正文的阅读舒适度不让步 |

::: info 演进
上一版叫"格墨"：夜蓝墨色、像素小狼、Bricolage Grotesque 标题字，更早还有六套可换的配色。2026-11-12 用 impeccable 技能重定方向，用户从一轮方向稿里选了"动物园导览图"的理念（大块可辨的区域代替密密麻麻的列表），配色和细节按成年用户成熟化，就是现在的石与苔（`desktop@cbd6940`）。
:::

## 信息层级

从上到下越来越安静。

| 层 | 内容 | 表现 |
|---|---|---|
| 1. 需要你 | 审批、提问 | 全界面唯一铺赭色底的东西（`accent-soft` 的大圆角区域）。流之外还有回响：侧栏的"等你"、区域的"N 件等你"、标题栏的"N 件等你"、输入框上方的状态行 |
| 2. 结果 | 你的话、回答、这一轮改动的文件 | `fg`、`text-body`，页面的主体；改动的文件是回答下面的文件卡片 |
| 3. 过程 | 推理、工具调用、子 agent、计划 | 一轮结束后收成一句人话（"看了 9 个文件，运行了 2 条命令"），放在回答后面，展开见全部 |
| 4. 元信息 | 模型、时长、用量 | `fg-subtle`、`text-small`，只在指向或聚焦这一轮时出现 |

## 一个信号，其余安静

- **赭色只说"需要你"**：等你的胶囊、审批和提问卡片、等你的计数。选中、默认、链接、搜索高亮、进度都不用它。失败用更冷的 `danger`，不会被读成"等你"。
- **动作是苔色**（`ink`）：主按钮、发送、开关的开、复选框、链接、进度。一块区域最多一个苔色实心按钮。
- **成功是常态，不着色。** 只有失败、等待、被拒才有标记；被拒是你的选择，不用红色。
- **分区靠底色和留白，不靠线。** 色块是 `surface`，色块里的缝用画布色（`divide-canvas`）；卡片没有边框。
- **一切按钮、标签、会话行都是胶囊**；区域和卡片是大圆角。
- **不用标题上方的小字标签**（eyebrow），标题自己说话。

## 窗口

- 窗口底色是 `ground`（石色），侧栏直接画在上面，宽 280。
- 当前屏幕是一张 `canvas`（纸色）的大工作面，四周离窗口 10px，圆角 28px，和侧栏之间不画线。
- 屏幕标题栏高 64，也是拖动区；内容滚到它下面时渐隐。
- **侧栏是导览图**：顶部"新的事"苔色胶囊（`⌘N`）和搜索、定时任务；下面每个工作区一块区域色的圆角区域，区域标题写名字、件数和"N 件等你"；会话行尾按优先级只显示一个：等你 > 在做 > 未读圆点 > 相对时间。红绿灯那一行右端是 ollupi 字标。
- **对话页标题栏**：左边区域标签和标题；右边"N 件等你"（有时），然后是浏览器、文件两个面板胶囊和"更多"（环境、终端、任务、上下文、导出，每项一句说明）。
- **最小窗口 860×560**：输入框工具栏按顺序让位（模型先收成图标）；侧面板改为从右边盖在对话上；记忆、能力、设置的竖排导航变成内容上方一排胶囊。

## 主题

石与苔是默认主题，另有一套**暮色**，在设置 → 外观里选，各有浅色、深色。主题只是一组 token，组件不用改。

暮色的灵感是傍晚：窗口底色是纸，四角渗进薰衣草、蜜桃、雾蓝的光；一层细颗粒盖住整个窗口，纸面和底色是同一张纸，像印刷品，纸面只是更亮更静。动作色是暮靛，"需要你"仍只用一个暖色信号（日落红）；工作区是取自同一片天光的粉彩色块。深色是入夜后的靛紫。

暮色下还有几样草原的小东西，和暮色小狼同一种画法（颗粒、溶解的边缘）：侧栏顶部一只蜻蜓，新会话页问候上方一小幅地平线（草丛、金合欢、飞鸟、萤火），空状态的小狼脚边两簇草和两点萤火。它们只放在真正空着的地方，不压文字和控件，对话页不放；Dock 图标和圆形标识也换成暮色小狼（见 [品牌](/zh/desktop/brand)）。

::: info 演进
2026-11-14 加入暮色，灵感来自一组傍晚主题的品牌视觉。第一版只换了配色、颗粒几乎看不见，用户觉得"没有那种质感"：差在颗粒要看得见、图像边缘要溶解成颗粒、光要一团团晕开。点缀第一次放在侧栏左下角和新会话页下角，压到了"记忆""已连接"和输入框，改成只放空处。颗粒原先只画在底色上，纸面是光滑的，两种材质在纸面边缘断开，显得不自然；改成一层颗粒盖住整个窗口。见 [决策 25](/zh/reference/decisions#_25-主题-石与苔之外的暮色)。
:::

## Token

`theme.css` 的 `@theme` 用 `initial` 清掉 Tailwind 默认的色板、字号、圆角、阴影和缓动，只留这里定义的档位，越界的写法不生成样式。组件只用语义名（`bg-canvas`、`text-fg-muted`、`rounded-3xl`），深色和主题都不需要逐个组件写：语义类名映射到 `--ol-*` 变量，`:root` 是石与苔，`[data-theme='dusk']` 是暮色，各有一份浅色和一份 `prefers-color-scheme: dark` 的深色。悬停、选中、线、遮罩、阴影都由 `--ol-tint` 调出来，改颜色只改基础值。

### 颜色

| token | 浅色 | 深色 | 用于 |
|---|---|---|---|
| `ground` | `#eeede8` | `#151716` | 窗口底、侧栏 |
| `canvas` | `#f8f7f4` | `#1d201f` | 屏幕工作面 |
| `surface` | `#eeede8` | `#262a28` | 色块：设置卡片、文件卡片、用户消息、输入框外壳 |
| `raised` | `#ffffff` | `#272b29` | 对话框、菜单、选择浮层、toast |
| `fg` | `#22252a` | `#ecedea` | 正文、标题 |
| `fg-muted` | `#4c5057` | `#adb3ab` | 次要说明、过程行、区域里的次要文字 |
| `fg-subtle` | `#63676e` | `#8e948c` | 时间、时长；只放在纸和石上 |
| `ink` | `#263b30` | `#cfe0c9` | 动作 |
| `accent` / `accent-soft` | `#a84a2b` / `#f6e1d7` | `#e58b66` / 16% | 只表示"需要你" |
| `danger` | `#a3264a` | `#f08aa6` | 失败、完全访问、危险按钮 |
| `area-1`…`area-6` | 苔 `#bccbb4`、雾 `#bfccd6`、石楠 `#cfc7db`、燕麦 `#d9cfb8`、鼠尾草青 `#b5ccc7`、灰鼠尾草 `#c9cdbf` | 同色族深色 | 工作区的颜色 |

- 区域色都是低饱和的雾色，不放红色系，免得被当成提醒。工作区按 id 稳定地分到六色之一（`views/common/areas.ts`），侧栏怎么排序都不变色。
- 正文、次要文字、苔色和赭色在画布、石色、区域色上都达到 WCAG AA。`fg-muted` 在六种区域色上都在 4.7:1 以上，所以区域里的次要文字用它；`fg-subtle` 只放在纸和石上。
- 浮层在深色里加一圈 `ring-1 ring-line`：深色的 `raised` 和石色几乎一样亮。
- 选中文字用苔色调的底，不用系统蓝。

### 字号

| class | 字号 / 行高 / 字重 | 用在 |
|---|---|---|
| `text-caption` | 11 / 16 / 500 | 胶囊里的状态词、快捷键提示 |
| `text-small` | 12 / 18 / 400 | 元信息、区域名、辅助说明 |
| `text-ui` | 13 / 20 / 400 | 界面默认 |
| `text-body` | 15 / 24 / 400 | 对话正文 |
| `text-title` | 15 / 22 / 600 | 屏幕标题、对话框标题 |
| `text-display` | 20 / 28 / 600 | 审批和提问的问题、页面分节标题、面板第一层的一句状态 |
| `text-hero` | 28 / 36 / 600 | 新会话页的问候 |

字重只用 400、500、600。字体是 Manrope + 苹方，代码用 JetBrains Mono，都打包进应用。中文界面时字体栈最前面是 `CJK Punctuation`，引号、破折号、省略号用苹方的字形。不加字距、不用全大写、中文不用斜体。命令、路径、文件名用等宽；模型在第一层只写模型名，不写"服务商/模型"。

### 圆角、阴影、动效

| 圆角 | 用于 |
|---|---|
| `rounded-full` | 所有按钮、胶囊、标签、会话行、导航项 |
| `xl` 12 | 输入框的井 |
| `2xl` 16 | 代码块、浮层、附件、色块里的命令行 |
| `3xl` 22 | 区域、设置和列表色块、用户消息、文件卡片、toast |
| `4xl` 28 | 屏幕工作面、输入框外壳、审批和提问卡片、对话框 |

阴影只三档：`sm` 侧栏里打开的那一行，`md` 菜单、toast、浮动胶囊，`lg` 对话框；区域、色块、卡片没有阴影。动效 100 / 160 / 240ms 三档，缓动统一；"在做"是状态行前一个缓慢呼吸的苔色圆点，加载是三个依次变深的圆点（前 300ms 不显示）；遵守 `prefers-reduced-motion`。

## 组件要点

- **结果在前。** 一轮按"你的话 → 回答 → 改动的文件 → 过程"排。这一轮写入的文件在回答下面列成文件卡片（文件名、所在文件夹、打开）。
- **审批卡片。** 标题是问题本身；下面是要做的事（命令、文件）和一句后果（"在「某某」文件夹里运行。"、只改这一个文件）；命令所在文件夹、diff、理由和"以后…都可以"收在"看细节"里。三个答案：先不要（Esc）/ 这件事里都可以 / 可以（↵）；完全访问不绑 ↵，默认焦点在"先不要"。
- **审批策略说人话**：什么都先问我 / 要紧的先问我 / 放手去做（严格 / 适中 / 宽松），"放手去做"用警告色。
- **输入框。** `surface` 的大圆角外壳，工具栏是纸色胶囊；发送是 40px 的苔色圆。
- **新会话页。** 问候、所在文件夹的名字，下面最多四张"可以从这些开始"的卡片，只来自真有的东西（选了的文件夹、装了的技能、定时任务、浏览器、记忆）；点一下把文字写进输入框，不发送。
- **侧面板先结论。** 上下文先说"还很宽裕 / 快满了 / 满了"和它会自动做什么；环境先说"改了 N 个文件"；组成、调用、路径、分支收在"细节"里。
- **记忆、能力、设置。** 每页开头一句人话；内置工具按用途分组，工具 id 收在展开里；添加模型先选服务（DeepSeek、通义千问、Kimi、智谱、OpenAI、Anthropic、Gemini），只剩粘贴密钥。
- **选择浮层**（模型、审批策略、更多）：`Picker` 组件，分组、长列表可查找、`↑` `↓` `↵` `Esc`。
- **可展开的细节**：`Details`（一行小字加箭头）和 `ClampText`（2–3 行，被截断才出现"展开"）。
- **小狼**只在空状态和第一次出现，见 [品牌](/zh/desktop/brand#小狼的姿势)。

## 文案

中文和英文同等重要，两份词表同时改；改完在 860 宽的窗口里两种语言各看一遍。

- **说人话。** 第一层写用户的事："新的事"不写"新建会话"，"等你在上方点个头"不写"等待审批"，"看了 9 个文件"不写 `read_file ×9`。
- **平实、直接、体面。** 不用感叹号，不卖萌，不堆砌道歉。
- **按钮动词开头，** 说出结果。英文用 sentence case。
- **出错三段：** 什么失败了，为什么，能做什么；不知道原因时给原始错误，不编解释。

## 检查

改完一个界面：任意值写法（`text-[`、`rounded-[`、`bg-[#` 等）、全大写、`font-bold`、`tracking-` 都不该出现；赭色只出现在"需要你"的信号上；一个区域最多一个主按钮；成功不着色；不用边框和分隔线分区；按钮都是胶囊。最后开着开发版用 `impeccable detect --cdp` 在浅色、深色下各扫一遍。
