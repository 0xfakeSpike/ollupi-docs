# 工作区与会话

工作区是你的一个项目文件夹，会话是你和 agent 的一段对话。这一页讲怎样组织它们，以及和 agent 对话时能做什么。

## 工作区

工作区就是一个项目文件夹。agent 读写文件、运行命令都在这个文件夹里进行，权限也可以按工作区来设。

- **添加**：点侧边栏底部附近的 **添加工作区**，选一个文件夹。
- **管理**：把鼠标移到侧边栏里的工作区名字上，可以在 Finder 里打开文件夹、进入工作区设置、归档，或在这个工作区里新建会话。
- **工作区设置**：可以改名称、改权限，也可以把整个文件夹搬到别的地方。搬家时选一个已经存在的空文件夹，会话、记忆和定时任务都会跟着走；有会话正在运行时不能搬。
- **归档**：归档的工作区从侧边栏收起，可以在已归档列表里恢复。

不选工作区也能聊天，这时 agent 的命令在 `~/.ollupi/scratch` 里运行。

## 环境

环境是会话的命令在哪里跑。**这台电脑**是一个，你还可以登记自己命名的云端沙箱。

- **选择**：新建会话时在 **环境** 里选。不选就是这台电脑。会话一直留在它开始时的环境里，之后改不了；子 agent 跟着父会话。
- **管理**：点 **管理环境…**，可以添加云端沙箱的名字、点名字改名、删除。这台电脑删不掉；有会话在用的环境也删不掉，删除会失败。
- **在哪看**：不在这台电脑上的会话，标题旁边会标出环境的名字。

现在这一版只在这台电脑上跑命令：在云端沙箱里开始的会话，命令会被拒绝，agent 会告诉你换到这台电脑上开会话。登记云端沙箱是为以后接入做准备。

## 会话

侧边栏按工作区分组列出会话。

- **新建**：点 **新会话**，在输入框的工具栏里选工作区和模型，输入第一条任务。会话标题取这条消息的开头。
- **重命名**：双击侧边栏里的会话，或点标题栏里的标题。
- **归档和删除**：归档的会话不再接收新消息，它的定时任务也不再发送，可以在已归档列表里恢复。删除会一并删掉它的子 agent 会话、附件和定时任务。
- **导出**：可以把会话导出成 Markdown，或者包含全部记录的 JSON。

## 和 agent 对话

按 Enter 发送。agent 工作时你可以继续输入：

| 操作 | 按键 | 效果 |
|---|---|---|
| 插话 | Enter | agent 马上看到这条消息，并据此调整正在做的事 |
| 排队 | ⌥Enter | 等这一轮做完，再作为下一条消息发送 |
| 停止 | 输入框里的方块按钮 | 结束这一轮 |

**附件**：可以粘贴、拖入或选择图片和文本文件，发送前能预览，每条消息最多 10 个。如果选的模型不支持图片，发送会被拒绝，而不是悄悄丢掉图片。

**回复里的文件**：agent 回复里提到的工作区文件可以点。单击在文件面板里打开，⌘+点击用默认应用打开。

**用量**：每一轮下面显示这一轮用了多少 token，包括命中缓存的部分。

## 子 agent

遇到可以拆开做的任务，agent 会派出子 agent 去做其中一部分。时间线里能看到子 agent 的进度，也可以点进去看它的完整会话。子 agent 的会话是只读的，有话要说就在父会话里说。

## 搜索

按 ⌘K 搜索会话标题、消息、定时任务和记忆。多个词时要全部命中，也可以只搜某个工作区。点结果会直接跳到那一条。

## 常用快捷键

| 按键 | 作用 |
|---|---|
| Enter | 发送；一轮运行中是插话 |
| Shift+Enter | 换行 |
| ⌥Enter | 一轮运行中排队 |
| ⌘K | 搜索 |
| ⌘Enter | 在改动面板里提交 |
| ⌘+点击 | 用默认应用打开文件 |
| ⌘Q | 退出应用 |

关掉窗口不会退出。应用留在后台，会话照常运行，通知照常发。点 Dock 图标回来，要退出用 ⌘Q。
