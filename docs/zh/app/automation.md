# 定时任务与记忆

定时任务让 agent 按时做事，记忆让它记住你的偏好和项目里的决定。这一页讲怎样使用它们。引擎里的实现见[定时任务](/zh/engine/cron)和[记忆](/zh/engine/memory)。

## 定时任务

定时任务就是到点给某个会话发一条消息，比如"每个工作日早上 9 点，总结昨天的 git 提交"。消息到了以后，agent 像收到你发的消息一样处理：会话空闲就开始，正在忙就排队。

### 新建

在侧边栏打开 **定时任务**，点新建，填这几项：

| 项 | 说明 |
|---|---|
| 工作区和会话 | 消息发到哪个会话，这个会话的历史、模型和权限都会沿用 |
| 名称 | 方便你在列表里认出它 |
| 时间 | 仅一次、每小时、每天、工作日、每周或每月 |
| 次数 | 重复任务发送满这么多次后自动删除；不填就一直重复 |
| 消息 | 到点发送的内容 |

也可以直接在对话里让 agent 帮你建，比如"每周一早上提醒我检查依赖更新"。

### 管理

列表里显示每个任务的下次运行时间、上次发送时间和已发送次数，可以按工作区筛选，也可以暂停、恢复和删除。

几种不会发送的情况：任务被暂停，所在的会话或工作区被归档，或者目标是子 agent 会话。

应用关着的时候任务不会运行。下次打开应用时，错过的任务会补发一次。

## 记忆

agent 会从你们的对话里学习，记住以后用得上的东西，比如：

- 你的偏好：喜欢的代码风格、回复的语言。
- 项目里的决定：选了哪个库、为什么。
- 做事的流程：怎样发布、怎样跑测试。
- 验证过的事实。

学习在后台进行，不会打断对话。新会话开始时，agent 会载入相关的记忆；其余的在需要时自己去搜。

### 范围

记忆分三种范围：全局的（对所有会话有效）、不属于任何工作区的会话的，以及每个工作区自己的。项目相关的内容只在那个项目里用。

### 查看和修改

在侧边栏打开 **记忆**，可以按范围浏览和搜索。每一条都可以：

- **编辑**：改正说错的地方。
- **遗忘**：删掉这一条。
- **移到全局**：让它对所有项目都有效，也可以移回去。

你改过或遗忘过的条目，agent 以后不会自动覆盖。

### 设置

在记忆页的设置里可以关掉"从会话学习"或"在会话中使用"，也可以选用哪个模型来提炼记忆。记忆页还显示学习进度：有多少条有效记忆、还有多少轮对话等着学习、失败的原因和下次重试时间。
