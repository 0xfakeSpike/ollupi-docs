# 定时任务与记忆

定时任务让 agent 按时做事，记忆让它记住你的偏好和项目里的决定。这一页讲怎样使用它们。引擎里的实现见[定时任务](/zh/engine/cron)和[记忆](/zh/engine/memory)。

## 定时任务

定时任务就是到点给某个会话发一条消息，比如「每个工作日早上 9 点，总结昨天的 git 提交」。消息到了以后，agent 像收到你发的消息一样处理：会话空闲就开始，正在忙就排队。

### 新建

在侧边栏打开 **定时任务**。左侧按 **全部**、**无工作区** 和各工作区分开看；**新建任务** 的表单就在这一页底部，不用另开窗口，填完点 **创建任务**：

| 项 | 填什么 |
|---|---|
| 工作区 | 任务属于哪个项目。不列出已归档或还没有会话的工作区 |
| 会话 | 消息发送到的会话，这个会话的历史、模型和权限都会沿用。这里列出该工作区最近的会话；还没有会话时会提示你先开始一个 |
| 名称 | 在所属会话里唯一，方便你在列表里认出它 |
| 运行时间 | 仅一次、每小时、每天、工作日、每周或每月，按这台电脑的本地时间。选了已经过去的时间会提示；每月某一天而那个月没有这一天时，那个月跳过 |
| 次数 | 发送满这么多次后任务结束。留空（不限）就一直重复，直到删除 |
| 消息 | 到点发送的内容 |

也可以直接在对话里让 agent 帮你建，比如「每周一早上提醒我检查依赖更新」。

### 列表里看到什么

每条任务写着名称、发送频率（比如「每天 09:00」「工作日 09:00」「仅一次：…」）、总共发送几次和发送到哪个会话。下面一行是 **下次：…**，暂停时写着 **已暂停**；再下面是上次发送的时间和已经发送了几次，还没发过时写「还没有发送过」。

右侧的开关暂停和恢复这条任务，垃圾桶删除它，删除前会问「删除任务“名称”？」。

### 什么情况下不会发送

- 任务被暂停。
- 它所在的工作区已归档，或它发送到的会话已归档；任务上会标出「工作区已归档，期间不会发送」或「会话已归档，期间不会发送」。
- 目标是子 agent 的会话。

应用关着的时候任务不会运行。错过的那一次不会补发，到了下一个设定时间再发。

### 中枢和定时任务

定时任务发送到中枢会话时，由中枢把这件事交给对应项目的会话去做，见[中枢](/zh/engine/hub)。

## 记忆

agent 会从你们的对话里学习，记住以后用得上的东西，比如：

- 你的偏好：喜欢的代码风格、回复的语言。
- 项目里的决定：选了哪个库、为什么。
- 做事的流程：怎样发布、怎样跑测试。
- 验证过的事实。

学习在后台进行，不会打断对话。新会话开始时，agent 会载入相关的记忆；其余的在需要时自己去搜。

### 范围

记忆分三种范围：全局的（对所有会话有效）、不属于任何工作区的会话的，以及每个工作区自己的。项目相关的内容只在那个项目里用。

### 查看和修改

在侧边栏打开 **记忆**，可以按范围浏览和搜索。每一条都可以：

- **编辑**：改正说错的地方。
- **遗忘**：删掉这一条。
- **移到全局**：让它对所有项目都有效，也可以移回去。

你改过或遗忘过的条目，agent 以后不会自动覆盖。

### 设置

在侧边栏打开 **记忆**，选 **全局**，上方是记忆的设置：

| 想做的事 | 怎么做 | 会发生什么 |
|---|---|---|
| 关掉记忆 | 关掉 **记忆** 开关 | 会话既不使用记忆，也不再学习新的。马上生效，不重启后端 |
| 只用已有的记忆，不学新的 | 关掉 **从会话中学习** | 已有的记忆照样使用。关着期间结束的会话，之后再打开也不会补学。马上生效，不重启后端 |
| 选学习用的模型 | 学习开着时，在下面的模型列表里选一个 | 每轮结束后由这个模型提炼值得记住的内容，消耗它的 token。换模型会改写配置并重启后端；没选模型时不会学新的 |

记忆页还显示学习进度：有多少条有效记忆、还有多少轮对话等着学习、失败的原因和下次重试时间。
