# 安装与上手

Ollupi 是 macOS 上的 AI agent 应用。你在自己的项目文件夹里和它对话，它能读写文件、运行命令、上网查资料，做有风险的事之前会先问你。这一页带你从下载到跑通第一个任务。

## 下载安装

需要 macOS 12 或更新，只支持 Apple 芯片（M 系列）。

1. 打开 [Releases](https://github.com/0xfakeSpike/ollupi-desktop/releases/latest)，下载 `Ollupi-<版本>-arm64.dmg`。
2. 打开 dmg，把 Ollupi 拖进「应用程序」。

要从「应用程序」里打开它，而不是留在下载文件夹或 dmg 里。应用内的自动更新要替换正在运行的这一份，放在别处时替换会失败，界面上会说明「Ollupi 无法替换 … 处的自己。请把它移到“应用程序”文件夹，再从那里打开。」

### 第一次打开

应用还没有经过 Apple 公证，第一次打开时 macOS 会提示无法验证开发者。点「完成」，然后选一种方式放行：

- 打开 **系统设置 → 隐私与安全性**，拉到底部，点 **仍要打开**。
- 或者在终端里执行：

  ```bash
  xattr -dr com.apple.quarantine /Applications/Ollupi.app
  ```

只需要做一次。

## 更新

侧边栏底部出现「Ollupi X 可以更新了。」时，点 **下载并安装**。下载期间同一行显示进度；下完之后提示变成「Ollupi X 已下载好。」，旁边说明「重启即可完成安装；不重启的话，退出 Ollupi 时也会安装。」，点 **立即重启** 马上装上。

- **稍后**：这次先不装。下载好的版本留着，下次退出应用时安装。
- **更新内容**：这一版改了什么。

也可以随时到 **设置 → 通用** 的 **版本** 一行点 **检查更新**，这一行旁边还有 **更新内容** 的链接。已经是最新时提示「Ollupi X 已是最新版本。」；检查失败时提示「检查新版本失败。」，可以再点一次。下载失败时提示「更新到 Ollupi X 失败。」。

自动更新只对装好的应用生效：从别处运行时这一行会说明「更新只对安装好的应用生效。」，要更新就去 Releases 重新下载。

## 添加模型提供方

Ollupi 不自带模型，要接你自己的 API。

1. 打开 **设置 → 模型**，点 **添加提供方**。
2. 先回答「你的密钥来自哪家？」，选 DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI、Anthropic、Gemini 之一，或者选 **其他…** 自己填接口。
3. 粘贴 API 密钥。对话框里写着「在 X 的开放平台创建一个密钥，粘贴到这里。它只存在这台电脑上。」，旁边的眼睛按钮可以显示或隐藏密钥。
4. 想改名字、接口类型或地址，展开 **高级：名称、接口和地址**。名称出现在模型选择里，不能带 `/`，也不能和已有的提供方重名；Base URL 留空就用这家 API 的默认地址。
5. 模型列表会自动拉取。用 **筛选模型** 找到要用的，勾上；**全选** 和 **清除** 一次处理全部。对话框右上角显示「已选 N / 总数」。
6. 上下限能自动填的都会填好，留空的项用灰色显示的默认值。本地小模型请按实际窗口填，窗口填大了，长对话会被 API 拒绝。
7. 点 **保存并重启**。后端重启完，新模型就能在输入框的 **模型** 里选到。

拉不到模型列表时，对话框显示「无法获取模型列表。」和原因，点 **重试**；也可以按提示 **请手动填写第一个模型。**

新安装的应用里已经有一个没填密钥的 `openai` 提供方。要用 OpenAI，就在 **设置 → 模型** 里编辑它，填上密钥。要用别家，就添加自己的提供方，再在模型列表里点这个模型右边的星标，把它设为默认（默认的模型带 **默认** 标记），然后删掉 `openai`。

每个模型都能改 **并发调用**、**思考**、**支持图片** 和 **Token 上限**：上下文、最大输入、输出。这些项的含义见[配置与数据](/zh/app/config#models)。

## 第一个会话

1. 在侧边栏工作区列表下面点 **添加工作区**，选一个项目文件夹。工作区就是一个项目文件夹，agent 的命令在里面运行。
2. 点侧边栏顶部的 **新的事**（⌘N），在输入框的工具栏里选工作区、模型、环境和审批策略。
3. 描述任务，按 Enter 发送。可以粘贴或拖入图片和文件，每条消息最多 10 个。

会话标题取第一条消息的开头。不选工作区也能聊天，这时命令在 `~/.ollupi/scratch` 里运行。

agent 工作时你可以继续输入，或者停下它，见[工作区与会话](/zh/app/sessions)。
