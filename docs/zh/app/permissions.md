# 审批与权限

agent 能读写文件、运行命令、上网。有些事做之前它会先问你，问哪些由审批策略决定。这一页讲怎样选策略，以及审批卡片怎么看。权限在引擎里怎么判定，见[权限与审批的机制](/zh/engine/permissions)。

## 选一档审批策略

审批策略有三档：

| agent 要做的事 | 严格 | 适中（默认） | 宽松 |
|---|---|---|---|
| 读文件、搜索 | 直接做 | 直接做 | 直接做 |
| 改项目里的文件、在沙箱里运行命令 | 先问你 | 直接做 | 直接做 |
| 抓取网页、在浏览器里点击或输入、会改动东西的外部工具 | 先问你 | 先问你 | 直接做 |
| 跑到沙箱外运行命令 | 先问你 | 先问你 | 直接做 |

拿不准就用适中：日常写代码、跑测试不会被打断，碰到项目以外的东西才问你。

- **严格**适合在重要的仓库里让 agent 只做分析，或者你想逐条看它要做什么。
- **宽松**适合你信任这个任务、不想被打断的时候，比如让它在一个临时目录里自己跑完一长串操作。

在哪里改：

- **工作区设置 → 权限**：对这个工作区里所有会话生效。
- 会话右上角的 **会话权限**：只对这个会话生效，正在进行的一轮从下一步起就用新设置。

## 沙箱是什么

agent 运行的命令默认在沙箱里执行。沙箱是一道安全围栏：命令只能改工作区和临时目录里的文件，读不到 SSH 密钥、云服务凭据这类文件，也改不了 `.envrc`、`.vscode` 这类之后会被其他程序自动执行的配置。

有些命令在沙箱里做不成，比如往系统目录安装软件。这时 agent 会申请"在沙箱外运行"，并说明理由。跑到沙箱外的命令能访问你账号能访问的所有文件和网络，所以在严格和适中两档下都会先问你。

## 审批卡片

agent 要做需要确认的事时，对话里会出现一张卡片，写明它要运行的命令、要改的文件（带改动对比）或要打开的网址。你可以选：

| 按钮 | 意思 |
|---|---|
| 允许一次 | 只放行这一次 |
| 在此会话中允许 | 这个会话里一模一样的操作不再问 |
| 总是允许 | 写一条规则，以后同类操作都不问 |
| 拒绝 | 不做，agent 会收到拒绝，并据此调整 |

卡片标着"在沙箱外运行"时要多看一眼，这类操作不提供"总是允许"。

批准之后，agent 执行的就是卡片上显示的那条命令、那份改动。如果执行前它们变了，比如文件被别人改过，这次批准作废，会重新问你。

## agent 向你提问

有时 agent 需要你做个决定，比如在两个方案里选一个。对话里会出现一张提问卡片，你可以选一个选项，或者自己写答案。提交后它接着做。

应用不在前台时，需要审批、需要回答，或者一轮做完，都会发系统通知。侧边栏也会标出"等待你处理"的会话。

## 例外规则（高级）

大多数人不需要这一节。

在权限设置的 **例外（高级）** 里，可以为个别操作单独设规则，规则先于审批策略判定：

| 规则 | 效果 |
|---|---|
| 总是允许 | 直接做，不问你 |
| 总是先问我 | 即使审批策略允许，也先问你 |
| 禁止 | 永远不做，优先于上面两条 |

每行一条，写工具名，或者工具名加括号写明范围。例如 `run_command(git:*)` 表示所有 git 命令，`run_command(rm:*)` 表示所有 `rm` 命令。

在宽松档下，你设的禁止规则仍然有效。如果一条命令写得太复杂，没法对照规则检查（比如把命令藏在 `sh -c "$X"` 里），它会被拒绝，而不是被放过去。
