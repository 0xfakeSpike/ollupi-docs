# 面板：浏览器、文件、改动、终端

会话右上角有一排按钮，能在对话右侧打开一个面板，和对话并排显示。同一时间只开一个面板，切换会话时面板保持打开。

| 面板 | 用来 | 什么时候能开 |
|---|---|---|
| 浏览器 | agent 和你共用的网页浏览器 | 随时，新会话的草稿页也能开 |
| 文件 | 浏览、预览工作区里的文件 | 选了工作区之后 |
| 改动 | 看 git 改动，暂存、丢弃、提交 | 选了工作区之后 |
| 终端 | 你自己的命令行 | 选了工作区之后 |
| 任务 | agent 当前的计划和进度 | 会话开始之后 |
| 上下文 | 模型的上下文窗口用了多少 | 会话开始之后 |
| 会话权限 | 这个会话的审批策略和规则 | 会话开始之后 |

拖动面板左边缘可以调宽度，双击边缘恢复默认宽度。每个面板记住自己的宽度。

## 浏览器

内置浏览器由 agent 和你共用。agent 能打开网页、读内容、点击和输入；你看得到它在做什么，也能随时接手。

- **登录**：agent 进不去需要登录的网站时，你在这里登录一次，之后 agent 就能用。登录状态长期保存在应用自己的浏览器数据里，不和 Chrome 共用。
- **标签页**：每个会话有自己的一组标签页，agent 在当前显示的那个标签页里操作。会话归档或删除时，它的标签页会关掉。
- **收藏和历史**：地址栏的星标收藏当前页，收藏列表里也能看到本机 Chrome 的收藏（只读）。历史记录在 **设置 → 通用** 里可以清除。
- **下载**：网页要下载文件时会弹出保存对话框，默认存到"下载"。

在严格和适中两档下，agent 在浏览器里点击和输入之前会先问你，见[审批与权限](/zh/app/permissions)。

## 文件

只读浏览工作区里的文件。

- 文本、图片和 PDF 可以直接预览，Markdown 默认渲染显示，也能切换成源码。
- 打开的文件上方显示它在工作区里的路径，可以复制完整路径。
- 用默认应用打开：⌘+点击文件。

## 改动

列出工作区相对上次 git 提交的改动：修改、新增、删除和未跟踪的文件，点开看逐文件的对比。

- 暂存和取消暂存，可以单个文件，也可以全部。
- 丢弃改动之前会先确认。没提交过的文件会移到废纸篓，不会直接删掉。
- 写好提交信息，⌘Enter 提交已暂存的文件。

## 终端

每个工作区一个终端，在工作区目录打开。这是你自己的命令行，不经过 agent，也不在沙箱里。关掉面板后终端继续运行。

## 任务和上下文

- **任务**：agent 做多步骤的工作时，会在这里列出计划和完成进度。
- **上下文**：显示模型的上下文窗口被系统提示词、工具定义、消息和记忆各占了多少，离自动压缩还有多远，以及最近几次模型调用的缓存命中情况。对话很长、回答变慢或变贵时，可以来这里看看。
