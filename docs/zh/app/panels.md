# 浏览器、文件、环境与终端

每个会话在对话右侧有自己的面板。打开网页、翻一个文件、看 agent 这次改了什么、自己敲几条命令，都不用离开对话。面板跟会话绑定：切到别的会话再回来，原来开着的面板、翻到一半的文件都还在，两个会话可以各自开着不同的面板。

## 打开和关闭

会话头部有一排胶囊按钮，一个面板一个。点一下打开，再点一下关掉；同一时间一个会话只开一个面板，打开另一个时前一个收起。打开着的那一个是深色。窗口窄的时候头部只留图标，鼠标停在上面能看到名字。

胶囊后面的菜单里是导出：**导出为 Markdown** 和 **导出全部（JSON）**。

| 面板 | 用来 | 什么时候出现 |
|---|---|---|
| 浏览器 | agent 和你看同一个浏览器 | 随时，包括还没发出第一条消息的新会话 |
| 文件 | 浏览工作区里的文件 | 选了工作区之后 |
| 环境 | 看改了什么，暂存、提交 | 选了工作区之后 |
| 终端 | 你自己的命令行 | 选了工作区之后 |
| 任务 | agent 这次列的计划和进度 | 会话开始之后 |
| 上下文 | agent 现在记着多少内容 | 会话开始之后 |
| 待办 | 你要办的事分到了哪个项目 | 中枢会话 |

文件、环境、终端按工作区共享：同一个工作区的几个会话，看到的是同一棵树、同一份改动、同一个终端。

还有两样东西不在这排胶囊里：

- **会话权限**在消息框上方的审批策略菜单里，点 **此会话的权限规则…** 打开，见[审批与权限](/zh/app/permissions)。
- **用量**在 **设置 → 用量**：近 7 天或近 30 天消耗的 token，按天、按工作区和按模型分别列出。记忆抽取不计入；会话或工作区删除后，记录仍保留。

面板和对话并排，拖面板左边缘可以调宽，双击边缘恢复默认宽度。每个面板各自记住宽度。

## 浏览器

内置浏览器由 agent 和你共用。agent 在你看得见的那一个标签页里打开网页、点按钮、输入文字；你看到的就是它看到的，也可以随时接手。

- **标签页跟着会话**：每个会话一组自己的标签页，切到别的会话再回来还在。会话归档或删除时，它的标签页关掉。
- **地址栏**：新标签页打开的是 Google。输入的内容不是网址时，按 Google 搜索处理；输入时下方列出访问过和收藏的网页。
- **收藏**：「我的收藏」里除了你收藏的网页，还有这台 Mac 上 Chrome 各个配置的书签，只读。
- **历史记录**：面板里可以搜索、单条删除，也可以整个清除。清除后地址栏不再补全访问过的网页，收藏不受影响。
- **登录**：需要登录的网站，你在这里登录一次，之后 agent 就能用。登录状态保存在应用自己的浏览器数据里，不和 Chrome 共用。
- **下载**：网页下载的文件存到「下载」文件夹，面板里显示存到了哪里，可以在访达中显示。
- **填网页表单**：可以让 agent 把一段内容直接放进网页的编辑器，带格式的内容保留标题、粗体、列表和链接，空行分段。

网页要权限时会先问你。摄像头和麦克风、位置、屏幕、USB 设备这些每次都会问；通知、剪贴板、全屏这类按网站问一次并记住。对话框上写着哪个网站想用什么，选 **允许** 或 **拒绝**，下面一行说明这个选择会记在这个网站上，还是下次还会问你。应用不支持的请求直接拒绝。

在严格和适中两档下，agent 在浏览器里点击和输入之前会先问你，见[审批与权限](/zh/app/permissions)。

## 文件

只读浏览工作区里的文件。

- 单击文件夹，列出它里面的文件；双击文件夹，回到文件列表里它的位置（**在文件列表中显示**）。
- 文本文件显示内容；Markdown 默认显示渲染结果，可以切到 **查看源码**，再切回 **查看预览**。
- 文件很大时只显示开头部分。图片、PDF 这类不是文本的文件不显示内容，只标出类型和大小。
- 打开的文件上方写着它在工作区里的路径，可以复制，也可以在访达中显示。

## 环境

列出工作区相对上次 Git 提交的改动：修改、新增、删除和新文件，点开一个看它改了什么。

- 暂存单个文件，也可以全部暂存或全部取消暂存；暂存之后又改过的文件会标出来。
- 丢弃改动之前会先确认，文件回到上次提交时的样子。还没提交过的新文件丢弃时移到废纸篓，不会直接删掉。
- 写好提交信息，点 **提交 N 个文件**。一个文件都没暂存时，按钮旁写着「暂存文件后才能提交」。
- 面板顶部写着这是哪台电脑上的哪个文件夹、在哪个分支上；不在分支上时，说明它停在哪个提交。
- 工作区没有用 Git 管理时，这里会说明没有版本记录可以对比。

## 终端

每个工作区一个 shell，在工作区目录里打开。这是你自己的命令行，不经过 agent。关掉面板后它继续运行，正在跑的任务不会被打断；shell 退出后，点上方按钮重新开始。

有些程序会接管鼠标（比如 tmux），这时按住 Option 拖动，仍然可以选中里面的文字。

## 任务和上下文

- **任务**：agent 做多步骤的工作时会把计划列出来，这里显示最近一次计划，写着完成了多少（「已完成 3/5」）和什么时候更新的。计划还没出来时，这里会说明。
- **上下文**：显示 agent 现在记着多少内容——一个状态（还很宽裕、快满了、满了）、一条用量条，和自动压缩的位置。到了那个点，它会把前面的内容收成摘要接着做，不用你管。往下是细节：提示词各部分各占多少、最近一次调用和历次调用。对话很长、回答变慢或变贵时，可以来这里看看。

## 待办

待办只在中枢会话里出现。你把要办的事告诉中枢，它列成清单，分到各个项目：每一行写着是哪个项目、哪个会话、备注和结果。已经有人接手的排在前面（**进行中**），还没分派的排在后面（**未分派**）。

- 勾选就是标记完成；鼠标停在一条上，可以标记完成、放弃、分派给别的会话（也可以改成不分派），分派时能按项目找会话。
- 下方的 **归档** 按月收起做完和放弃的待办。

中枢会话自己不碰文件，它把每件事交给对应项目里的会话，见[中枢](/zh/engine/hub)。
