# 执行轨迹

执行轨迹是一次运行留下的完整记录：模型说了什么、想了什么，调用了哪些工具、参数和结果是什么，谁批准了什么，用了多少 token。Ollupi 不单独"记日志"来得到它：每一步本来就要先写进数据库才能执行，所以轨迹是执行方式的副产品，不需要额外开销，也不会漏记。
