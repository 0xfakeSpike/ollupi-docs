# 文章

手册讲 Ollupi 做什么，文章讲为什么：设计背后的问题、和其他运行 agent 的方式比怎么样、测量结果说明了什么，包括测错了的地方。

每篇文章可以单独读，细节链接到手册。文章先以英文发布。

## 已发布

- **[AI 时代到来，你的用户画像的价值会被谁赚走？](/zh/articles/user-profile)** · 2026 年 11 月 11 日。二十年来，用户画像值的钱全被互联网平台赚走。现在你的画像有了三份：平台、大模型公司和你自己的个人 agent 各有一份。平台和大模型公司各自怎么赚，你能留下多少，取决于平台开不开放权限、AI 贵不贵。
- **[水在青天云在瓶：agent 的身首错位现象](/zh/articles/head-in-the-cloud)** · 2026 年 11 月 8 日。为什么 agent 的接入层、运行时和执行环境会被部署在不同的地方：九种部署形态、七个决定因素、每条边界上的工程问题，以及什么场景该用什么形态。单独有一节讲中国大陆，同样的软件在那里常被部署成另一种形态。

## 计划中

- **个人 agent 大部分时间在等。** 用数字算清"每个 agent 一个容器"的成本。
- **agent 运行时和持久化执行。** agent 运行时和 Temporal、Restate、DBOS 这类持久化执行引擎有哪些相同，又必须在哪里不同：模型调用不确定、工具调用可能已经生效、审批必须绑定实际执行的内容。
- **杀进程九十次。** agent 的崩溃语义：为什么 `pending` 和 `inProgress` 是两个状态，为什么被中断的工具调用要标记而不是重试。
- **审批到底在批准什么。** 把权限、沙箱、脱敏当作一条信任边界来讲。
- **消失的 3.9 秒。** 找出 3000 个活跃会话以上变慢的原因。
