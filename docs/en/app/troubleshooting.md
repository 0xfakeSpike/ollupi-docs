# Troubleshooting

This page is arranged by what you see: what it means, and what to do about it.

::: info Full page in Chinese
This page is being translated. The complete version is [in Chinese](/zh/app/troubleshooting).
:::

The full page covers:

- The window shows only "the backend cannot start"
- The backend refuses a configuration or skill folder
- A change to the configuration or a skill has not taken effect
- Model errors, retries and the model list
- A command stopped by the sandbox
- An MCP server that is not connected
- "Reconnecting…" in the sidebar
- Where the logs are
- Starting over
