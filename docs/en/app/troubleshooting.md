# Troubleshooting

This page is arranged by what you see: what you see, why, and what to do. Each section ends with a link to the page that covers the topic in full.

::: info Full page in Chinese
This page is being translated. The complete version is [in Chinese](/zh/app/troubleshooting).
:::

The full page covers:

- The window shows only "the backend cannot start"
- The configuration has an error and the backend refuses to start
- A change to the configuration or a skill has not taken effect
- Model call errors: a turn that stops at "this turn failed"; 429s, server errors and dropped connections; a model list that cannot be fetched
- A command stopped by the sandbox
- An MCP server shown as "not connected"
- "Reconnecting…" in the sidebar
- Where the logs are
- Starting over
