# Skills, MCP and tools

What the agent can do depends on the tools and skills it has. **Capabilities** in the sidebar gathers them in one place, in three sections: **Skills**, **MCP** and **Built-in tools**; when the window is narrow, they become a row of tabs along the top that you can swipe sideways. This page covers adding skills, connecting MCP servers, reading the marks on the built-in tool list, and which kinds of helpers can do work for the agent. How they are loaded in the engine and how they enter the context is on [How skills and MCP work](/engine/skills-mcp).
