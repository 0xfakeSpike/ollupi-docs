# Skills, MCP and tools

What the agent can do depends on the tools and skills it has. **Capabilities** in the sidebar gathers them in one place, with three sections: **Skills**, **MCP** and **Built-in tools**. Saving a skill checks it first, then restarts the backend; a change to an MCP server applies as soon as it is saved, with no restart.
