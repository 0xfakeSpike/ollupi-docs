# Glossary

This is the authoritative page for the site's terms. Each entry gives a one-line definition and its counterpart in the code; mechanisms are not explained here, and the links lead to the details. Every page links the first mention of a term here.

Identifiers, table names and field names in the engine entries are checked against ollupi v0.17.1; the desktop entries were checked earlier against the `ollupi-desktop` source and have not been checked again this time.
