# Search

`search` looks up a user's session titles, messages, scheduled tasks and memories in one call and returns the four groups apart. Queries are bounded (200 characters, 8 words, 5 seconds), the task group is still named `tasks`, and a search within a workspace returns that workspace's memories only.
