# Hub

The hub is the one place where a user plans all of their projects: the user says what they want done, the hub hands each piece of work to a session in the right project and explains it there, then comes back to see how far those sessions have got. The hub does not touch project files or run project commands itself; it gets work done through sessions.

The hub has two parts: a workspace called hub, and the hub main agent that answers in it. For what a workspace and a session are, see [Core concepts](/intro/concepts); for the kinds of workspace and their protocol methods, see [Workspaces and environments](/integrate/protocol/workspaces).
