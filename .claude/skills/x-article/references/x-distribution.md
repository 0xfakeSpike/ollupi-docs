# X 的分发：排序代码说了什么，对写法意味着什么

## 来源和可信度

- **排序代码**：xai-org/x-algorithm（https://github.com/xai-org/x-algorithm），X 在 2026 年 1 月开源的 For You 推荐流代码。下面的权重来自 `home-mixer/params/param.rs` 的默认值，文件头写着与线上配置开关的默认值同步，最近一次同步 2026-11-10。打分公式在 `xai-value-model/scoring.rs`。2026-11-11 读取。仓库说这些默认值由脚本同步成线上值，这是仓库自己的说法，没有独立核实。
- **官方说法**：2026 年 1 月的 100 万美元长文奖，X 公布的评判标准主要是"已认证用户首页时间线上的曝光量"，要求原创、至少 1000 字。
- **其余**（营销博客里的"长文多 40% 曝光""外链降权 50–90%"等）找不到出处，不要引用。

## 打分方式

模型预测读者看到这条帖子后会做出各种动作的概率，每个概率乘一个权重，加起来就是分数：

Final Score = Σ (weight × P(action))

停留时长这类连续项乘的是预测的秒数，不是概率。

| 动作 | 权重 |
|---|---|
| 复制链接分享 | 20 |
| 回复 | 5（双方互相关注时另加 15） |
| 私信分享 | 5 |
| 引用转发 | 5 |
| 关注作者 | 4 |
| 分享 | 2.118 |
| 转发 | 1 |
| 点赞 | 0.708 |
| 点开后停留时长（每秒） | 0.385 |
| 点击 | 0.274 |
| 打开链接 | 0.2 |
| 停留（是否停留） | 0.05 |
| 停留时长（每秒，未点开） | 0.0075 |
| 没有停留 | -0.02 |
| 屏蔽作者 | -31.2 |

| 举报 | -234 |

**读这张表要注意**：权重乘的是概率，代码注释说权重同时考虑了"动作价值和通常的发生率"（举报的基础概率比点赞低一千倍以上）。所以不能直接说"一次复制链接抵 28 个赞"。能确定的是方向。

## 其他机制

- **48 小时过滤**：超过 48 小时的帖子不进入推荐候选。一篇文章在推荐流里大约活两天。
- **圈外打折**：推给没关注你的人时，分数乘一个小于 1 的系数。
- **同一作者递减**：同一个人的第二、第三条帖子在同一次刷新里分数递减，有下限。
- **新作者扶持**：曝光量低（200 以下）的作者，发帖后 2 小时内的帖子会被往前提一些。
- **外链**：代码里没有找到对外链的显式惩罚，"打开链接"是正权重。外链的损失可能是间接的：读者离开 X，停留时长不再累计。这是推断。
- **长文 / Article**：读过的 README 和代码里没有提到对 Article 的特殊加权。

## 对写法的含义

| 代码里的事实 | 写法上的对应 |
|---|---|
| 分享（尤其私信、复制链接）权重最高 | 写成能当参考资料转给同事的东西：能单独截出去的图、能单独引用的结论、一张对照表 |
| 回复、引用权重高，互相关注的回复另有加成 | 文章里有一个明确、可以拿来讨论的论点；发布后作者亲自回复评论 |
| 关注作者权重 4，圈外打折 | 长期积累关注者比单篇爆款重要；主题一致，让人知道关注你能持续得到什么 |
| 点开后停留时长按秒累计 | 长文天然有利，前提是读者真的读下去：路标、例子、短段落都是为了让人读完 |
| 不感兴趣、静音、举报扣分极重 | 标题党、诱导互动、夸大断言按算法也是亏的 |
| 48 小时过滤 | 发布后几天用摘录帖把读者引回原文 |

## 发布配套

1. **发布帖**：一两句说出最反直觉的结论，配文中最能单独看懂的一张图。
2. **头两个小时**：作者亲自回复评论，认真回答质疑。
3. **之后几天**：两三条摘录帖，每条一张图加一个论点，能独立成立，指回原文。
4. **平时**：在同领域别人的帖子下写有内容的回复，这是让同行认识你最直接的方式。

衡量标准：不看单篇曝光，看关注者里同行的比例、收藏数、认真讨论的回复数、有没有人引用你的结论。

## 编辑器注意事项

以下来自社区 skill（sundial-org/awesome-openclaw-skills 的 `x-articles`），没有在 X 官方文档里核实：

- 嵌入的帖子会显示在内容块末尾，不在插入的位置；要用插入菜单，不要直接粘贴网址。
- 封面图建议 5:2（如 1792×716），正文配图 16:9 或 4:3。
- 撰写只能在桌面网页端；发布需要 X Premium。
- SVG 插图需要先导出成 PNG 再上传。
