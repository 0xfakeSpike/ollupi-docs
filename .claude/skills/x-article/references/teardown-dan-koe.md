# 参考样本拆解：Dan Koe《How to fix your entire life in 1 day》

- 网址：https://x.com/thedankoe/status/2010751592346030461
- 发布：2026 年 1 月 13 日，X Article
- 2026-11-11 读取时的数据：约 2.58 亿浏览、9 千回复、7.9 万转发、38.5 万点赞、100 万收藏（按 X 按钮顺序读出）。收藏是点赞的两倍多，读者把它当作要留着反复看的东西。
- 注意：作者本人有几百万粉丝，浏览量很大一部分来自这个基础，这一点没法照搬。要学的是讲解方法。

## 全文骨架

1. 开头（约 10 段）：站到读者一边 → 翻转 → 自曝失败 → 预告 7 个观点和一套要花一整天的练习 → 明说"值得收藏"。
2. 第 I–V 节：五个观点，逐层往下挖，从"身份决定行为"到"行为都有目的"，再到"身份如何形成"、"心智发展的阶段"、"智力是得到你想要的东西的能力"。
3. 第 VI 节：一套照着做的练习，早上、白天、晚上各一部分，连提醒自己的具体时间和问题都写好了。
4. 第 VII 节：用"电子游戏"一个比喻把前面所有零件收拢。

先讲道理，后给工具，最后用一个比喻收尾。

## 值得借的手法

| 手法 | 原文怎么做 | 换到技术文章 |
|---|---|---|
| 从读者已有看法出发 | 第一句是"你大概也觉得新年计划很蠢"，然后翻转成"问题在改变的方式" | 从读者熟悉的做法出发，比如"多数人给 agent 加记忆，就是让它多记笔记"，然后指出这样做漏掉了什么 |
| 自曝失败换信任 | "我放弃的目标比完成的多十倍" | 写自己踩过的坑、测错过的数字，用户的 index 页已经承诺"包括测错了的地方" |
| 交代全文 | 预告观点数量、练习要花多久、建议收藏 | 开头列出结论要点，说明分几部分、文末有什么可以带走 |
| 小标题即论点 | 前三节同一句式："你没到想去的地方，是因为……" | 小标题写成完整论点；平行的几节用平行句式，读者一眼看出结构 |
| 抽象后紧跟日常例子 | 讲身份，用健身的人：对他来说，克制自己才吃得下垃圾食品 | 每个概念后面跟一个读者每天碰到的例子，再跟一个领域内的真实例子 |
| 反过来说 | "健身的人要逼自己才吃得下垃圾食品"，比"健身的人很自律"好记得多 | 找概念里反直觉的一面，用一句反过来的话说出来 |
| 词源和步骤拆概念 | 控制论：先说希腊语词源"掌舵"，再拆成五步循环 | 定义一个概念时，先给直观来源，再拆成几步 |
| 多领域例子证明通用 | 船、恒温器、胰腺三个例子说明同一个反馈循环 | 用两三个不同场景的例子，说明这个规律不是个案 |
| 路标句 | 举例前一句"如果这不好懂，我们看个例子"；重点前一句"下面这句很简单但很多人没懂" | 见 SKILL.md "给读者指路" |
| 关键句单独成段 | 全文最重要的一句话单独一段 | 同样做 |
| 统一的列表格式 | 9 个发展阶段，每个都是"名称——一句话定义——生活场景" | 分类、选项、形态都用同一种格式列出 |
| 先给引语再展开 | 每节开头放一段名人引语 | 可以用，但引语要有准确出处，而且和本节论点直接相关 |
| 讲原因不只给建议 | 不说"要自律"，而是解释为什么自律会失败 | 不只说"该这样做"，要说清机制，让读者自己推出结论 |
| 可带走的工具 | 一整套带时间点的练习 | 检查清单、决策表、选型对照 |
| 疲劳点拉一把 | 练习结束后："内容很多，希望有用，还剩最后一块，再坚持一下" | 长文中后段放一个小结或总图 |
| 比喻收尾 | 愿景是获胜条件、一年目标是主线任务、月度项目是 Boss 战、每天的行动是日常任务、约束是游戏规则 | 结尾用一个比喻或一张总图把所有部分对上号 |

## 不能借的地方

这是一篇自我提升类文章，有些写法和"可信的专业人士"冲突：

- **断言很绝对**："任何目标都能实现"，给人贴"智力低"的标签。技术读者会立刻找反例。
- **引用理论很随意**：把几种心理学模型一笔带过，其中一个人名还拼错了。技术文章里引用必须准确，能点开核对。
- **开头铺垫太长**：大约十段之后才进入正文，前面是态度和预告。用户的规则是第一屏就给结论，开头只借它"站到读者一边、交代全文"的做法，不借它的长度。
- **标题是夸张承诺**："一天修好你的整个人生"。
- **大量剖析读者心理**：替读者说出他为什么失败。技术文章里换成读者遇到的具体问题。
- **文中插入订阅推广**：中段插了一段邮件订阅链接。用户的目标是信誉，不建议在正文里插推广。

一句话：学它的讲解结构，不学它的语气和断言。
